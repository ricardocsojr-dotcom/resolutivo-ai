# Lib — Filtro de Relevância por Tipo de Ato

| Ato | Entra na timeline? | Entra no estado da arte? |
|---|---|---|
| Inicial, contestação, réplica | Sempre | Resumo em 1 linha |
| Emendas e aditamentos | Sempre | Se mudaram pedido/causa de pedir |
| Decisão interlocutória com conteúdo | Sempre | Se afeta tese/prova/prazo |
| Despacho de mero expediente | Não | Não |
| Saneamento | Sempre (é o coração) | Sempre |
| Laudo pericial | Sempre + conclusão citada | Conclusão em 1 linha |
| Ata de audiência | Sempre | Compromissos assumidos |
| Sentença/acórdão | Sempre + dispositivo transcrito | Sempre |
| Juntada de guia/substabelecimento | Não | Não |
| Determinação não cumprida | **Sempre, com ⚠️** | **Topo da página** |
