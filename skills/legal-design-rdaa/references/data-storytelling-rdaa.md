# Data Storytelling RDAA

## Finalidade

Esta referência organiza dados já confirmados em uma narrativa visual útil. Ela não cria fatos, não estima valores, não escolhe tese e não substitui a revisão jurídica. O uso é opcional e fica restrito aos tipos A e B quando uma visualização realmente melhorar a compreensão.

## Sequência de construção

1. Defina a pergunta que o elemento visual deve responder.
2. Separe dados confirmados, dados ausentes e interpretações autorizadas.
3. Escolha a menor estrutura capaz de responder à pergunta.
4. Mostre comparação, sequência, proporção ou dependência sem ornamentação.
5. Vincule cada dado ao ID, documento, página, evento ou cálculo de origem.
6. Revise a leitura em preto e branco e em tamanho reduzido.
7. Passe o elemento pelo `verificar_visual_law.py` e pelo gate de publicação.

## Estruturas preferenciais

| Pergunta | Estrutura |
|---|---|
| O que aconteceu e em qual ordem | Linha do tempo rastreável |
| O que mudou entre versões | Quadro comparativo |
| Quais etapas dependem umas das outras | Fluxo lógico |
| Qual documento comprova cada ponto | Matriz de prova |
| Qual é a diferença entre pedidos ou valores calculados | Tabela objetiva |
| Qual é a síntese de uma peça longa | Quadro-resumo |

## Regras de fidelidade

Não use escala visual para sugerir risco quando o risco não estiver formalmente registrado. Não transforme ausência de prova em valor zero. Não use cor como único diferenciador. Não use narrativa de dados para tornar uma tese mais categórica do que os fatos sustentam.

Os tipos A e B podem receber elementos visuais tipados por meio do playbook. O tipo C não aciona esta referência como premissa. A identidade visual permanece a do RDAA, com ativos locais e paleta oficial. O elemento nunca grava diretamente no arquivo final e deve passar pelo candidato temporário e pela publicação protegida.

## Limites de redação

Títulos sem dois pontos e sem travessão. Texto sem dois pontos. Sem aposto explicativo entre parênteses ou travessões pareados. A visualização deve ser compreensível sem depender de um título proibido ou de uma legenda que infira fatos.
