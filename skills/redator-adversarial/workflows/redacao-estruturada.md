# Workflow — Redação Estruturada

## Antes de escrever (5 perguntas)
1. Quem julga? (vara/turma — jurisprudência local importa)
2. Qual o pedido exato e o resultado prático que o cliente quer?
3. Quais os 3 fatos que ganham o caso? (o resto é ruído)
4. Qual a melhor defesa/ataque do adversário? (a peça já responde a ela)
5. Qual o limite de páginas razoável? (juiz lê 10 min — densidade > volume)

## Estrutura padrão

```
I.   SÍNTESE (5-8 linhas — o caso inteiro; juiz decide aqui se lê com atenção)
II.  PRELIMINARES (se houver — da mais letal para a menos)
III. MÉRITO (1 seção por tese; fato → prova (fls.) → direito → conclusão parcial)
IV.  PEDIDOS (numerados, certos e determinados, com subsidiários explícitos)
```

## Regras de estilo
- Períodos curtos; uma ideia por parágrafo; verbos ativos
- Fato sempre com fls./doc; direito sempre com artigo; jurisprudência sempre verificada
- Negrito só no que decide o caso (máx. 1 por página); nada de MAIÚSCULAS gritadas
- Pedido subsidiário nunca implícito: "sucessivamente, caso não acolhido o pedido 1..."

Ao terminar: rodar **obrigatoriamente** `simulacao-juiz` + `simulacao-adversario`.
