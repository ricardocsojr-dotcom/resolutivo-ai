# Lib — Fragilidades Recorrentes por Tipo de Peça

| Peça | Fragilidade clássica | Consequência |
|---|---|---|
| Inicial | Pedido genérico fora das hipóteses do art. 324 §1º | Emenda/indeferimento |
| Inicial | Valor da causa incompatível com o pedido (art. 292) | Impugnação, custas complementares |
| Contestação | Impugnação genérica (viola art. 341) | Fatos presumidos verdadeiros |
| Contestação | Preliminar boa arguida depois do mérito, mal fundamentada | Preclusão prática |
| Réplica | Rebater tudo, inclusive o irrelevante | Dilui o que importa |
| Apelação | Falta de dialeticidade (art. 1.010, III) | Não conhecimento |
| Apelação | Preparo errado/faltante | Deserção (art. 1.007) — 🔴 fatal |
| REsp/RE | Dispositivo não prequestionado | Súmula 282/356 STF — não conhecimento |
| REsp | Rediscussão de fato/prova | Súmula 7 STJ — não conhecimento |
| Embargos de declaração | Usar para rejulgamento puro | Multa (art. 1.026 §2º) |
| Tutela de urgência | Perigo descrito com adjetivos, sem fatos | Indeferimento |
