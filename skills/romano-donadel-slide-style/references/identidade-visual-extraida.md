# Identidade visual Romano Donadel extraída de materiais de referência

## Fonte e finalidade

Esta referência consolida padrões observados em 12 apresentações enviadas pelo escritório, totalizando 106 slides, além de um relatório em PDF e do logotipo oficial fornecido por Ricardo. Ela existe para orientar a criação e a padronização de novos decks sem embutir apresentações de clientes no plugin.

## Padrões confirmados

| Elemento | Regra operacional |
|---|---|
| Formato principal | Use 16 por 9 quando o usuário não fornecer template. Preservar o formato de arquivo existente quando for uma edição |
| Fundo | Usar branco como base dominante |
| Logo Romano Donadel | Usar `assets/logo_romano_donadel.png`, sem recolorir, distorcer ou recortar |
| Posição do logo | Canto superior direito com margem de respiro. Na capa é aceitável logo centralizado conforme o layout solicitado |
| Hierarquia | Títulos curtos em caixa alta. Laranja marca seções e números relevantes. Preto e cinza organizam texto e dados |
| Estrutura | Trabalhar com grid, tabelas, painéis, diagramas, gráficos e blocos comparativos |
| Rodapé | Usar aviso de confidencialidade, data ou numeração de página de forma discreta e consistente |
| Imagem de capa | Preferir fotografia arquitetônica em preto e branco ou visual documental de baixo protagonismo |
| Dados | Reservar cores semafóricas para status ou risco somente quando houver legenda e significado explícito |

## Paleta oficial

| Papel | Cor |
|---|---|
| Fundo | `#FFFFFF` |
| Texto forte e números principais | `#000000` |
| Estrutura, dados secundários, bordas e rodapé | `#63666A` |
| Destaque, barra de seção, título secundário e dado crítico | `#F7A800` |

A paleta navy e dourada aparece em alguns arquivos legados. Não usá-la em novos slides e não reintroduzi-la ao padronizar apresentações existentes. Preserve apenas cores que sejam ativos de cliente ou códigos semânticos de gráficos já declarados.

## Tipografia

As amostras reais usam Calibri, Lato, Tahoma e Arial. Para decks novos, priorizar Lato. Se Lato não estiver disponível no ambiente, usar uma fonte sans-serif local compatível e registrar o fallback. Ao padronizar um deck existente, preservar Lato quando já estiver presente. Não usar tipografia decorativa.

## Assets locais

O logotipo oficial distribuído pela skill está em `assets/logo_romano_donadel.png`. O template inicial distribuído está em `templates/romano-donadel-base.pptx`. Toda imagem, logo ou template recorrente deve ser copiado para dentro do projeto ou da skill antes de ser usado. Não depender de caminhos do computador do cliente, uploads temporários ou URLs remotas.

## Componentes recorrentes

| Componente | Aplicação |
|---|---|
| Capa | Título de projeto, cliente, data e logo. Pode usar foto arquitetônica monocromática |
| Separador de seção | Barra vertical laranja, título curto e bastante espaço em branco |
| Resumo executivo | Indicadores grandes, cartões discretos, conclusão objetiva e fonte dos dados |
| Tabela gerencial | Título curto, cabeçalho claro, bordas cinza e laranja apenas em coluna ou célula decisiva |
| Dashboard | Gráfico simples, rótulos legíveis, leitura de risco e nenhum enfeite gratuito |
| Comparativo | Duas ou três colunas alinhadas. Mostrar critério, contraste e conclusão |
| Diagrama | Conectores ortogonais, caixas alinhadas e legenda quando a relação não for autoexplicativa |

## Proteção de conteúdo

Os materiais de cliente usados como referência não devem ser copiados para novas apresentações. Extrair apenas padrões de composição e de marca. Não reutilizar nomes, números, logotipos de cliente, mapas, dados, teses, gráficos ou imagens de casos anteriores.
