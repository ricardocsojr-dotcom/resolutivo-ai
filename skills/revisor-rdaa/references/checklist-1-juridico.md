# Checklist 1 — Revisão Jurídica Estratégica da Peça

Use este checklist quando o modo ativo for **JURÍDICO** (texto da peça, não PDF).
Execute item por item. Registre o resultado de cada bloco no relatório final.

---

## I. Estrutura geral

- [ ] A peça possui começo, desenvolvimento e fechamento claros?
- [ ] Existe progressão lógica entre os tópicos?
- [ ] A cronologia está linear e compreensível?
- [ ] Há salto argumentativo?
- [ ] Existe repetição excessiva de ideias?
- [ ] O texto parece escrito de uma única vez ou tem aspecto "Frankenstein"?
- [ ] Os títulos antecipam a tese ou são genéricos ("Dos Fatos", "Do Direito", "Mérito")?
- [ ] Algum título começa com "Da/Do/De/Dos/Das"? (evitar sempre — redacao-rdaa.md)
- [ ] A peça está excessivamente longa para o conteúdo apresentado?
- [ ] Existe excesso de contextualização irrelevante?
- [ ] O juiz entenderia o problema principal nas primeiras páginas?
- [ ] O polo ativo aparece antes do polo passivo no quadro/preâmbulo?

---

## II. Clareza e coerência

- [ ] Cada parágrafo possui apenas uma ideia central?
- [ ] O tópico frasal está claro na primeira frase de cada parágrafo?
- [ ] Há períodos excessivamente longos (mais de três linhas)?
- [ ] Há ambiguidades?
- [ ] Há frases que exigem releitura?
- [ ] A ordem direta foi respeitada (sujeito + verbo + complemento)?
- [ ] Existe excesso de voz passiva?
- [ ] Há excesso de abstrações sem prova?
- [ ] Os fatos relevantes possuem consequência jurídica explícita?
- [ ] O texto está denso sem ficar prolixo?

---

## III. Padronização terminológica

- [ ] A nomenclatura das partes permanece uniforme do início ao fim?
- [ ] Se começou "Réu", permaneceu "Réu" (não "Requerido", "Demandado", "Contestante")?
- [ ] Se começou "Autora", permaneceu "Autora" (não "Requerente", "Demandante")?
- [ ] A decisão é chamada sempre da mesma forma (não alterna "decisão" / "decisum" / "r. decisão" / "pronunciamento")?
- [ ] O contrato/documento possui nomenclatura uniforme?
- [ ] Há alternância desnecessária de termos?
- [ ] Os pedidos seguem a mesma lógica terminológica?

---

## IV. Vícios de redação

### Abertura repetitiva

- [ ] Há três ou mais parágrafos consecutivos iniciados pelo mesmo artigo?
- [ ] Pelo mesmo substantivo?
- [ ] Pelo mesmo sujeito ("A Autora...", "A Autora...", "A Autora...")?
- [ ] Pelo mesmo verbo ("Alega...", "Alega...", "Alega...")?
- [ ] Pela mesma estrutura sintática?

Variações válidas para substituição:
- "No caso concreto..."
- "Quanto ao ponto..."
- "Esse contexto demonstra..."
- "A documentação revela..."
- "Conforme consta dos autos..."
- "A leitura da decisão evidencia..."
- "Inexiste prova de..."
- "Mostra-se inadequada a conclusão..."

### Abertura defensiva

- [ ] Algum argumento começa por negação, ressalva ou justificativa defensiva antes de apresentar o objeto afirmativo?
- [ ] A fórmula “não se pretende”, “não se busca”, “não se trata”, “não se ignora”, “não se desconhece”, “não se cuida” ou equivalente pode ser substituída por uma abertura afirmativa sem perda de sentido?
- [ ] Se a negativa foi mantida, ela delimita o objeto, responde a uma afirmação concreta, afasta interpretação específica ou forma contraste jurídico necessário?
- [ ] Há recorrência da mesma fórmula ou três ou mais aberturas defensivas na peça? Reescrever ou justificar funcionalmente.

Uma abertura negativa isolada não é erro automático. A revisão deve avaliar a função argumentativa, não bloquear por palavra-chave.

### Conectivos repetitivos

- [ ] Há excesso de "Assim,"?
- [ ] Há excesso de "Dessa forma,"?
- [ ] Há excesso de "Desse modo,"?
- [ ] Há excesso de "Nesse sentido,"?

### Expressões terminantemente proibidas

- [ ] "cumpre salientar" — presente?
- [ ] "imperioso notar" — presente?
- [ ] "não se pode olvidar" — presente?
- [ ] "vale lembrar" — presente?
- [ ] "é crucial destacar" — presente?
- [ ] "em suma" — presente?
- [ ] "o mesmo / a mesma" como pronome — presente?
- [ ] "junto a / junto ao" para órgãos e instituições — presente?
- [ ] "através de" como meio/instrumento — presente?
- [ ] "digníssimo" / "DD" / "ilustríssimo" — presente?

### Outros vícios

- [ ] Excesso de advérbios em "-mente"?
- [ ] Repetição excessiva de palavras dentro do mesmo parágrafo?
- [ ] Adjetivação vazia ("grave ilegalidade", "absurda conduta")?
- [ ] Juridiquês arcaico?
- [ ] Parágrafos inflados sem ideia útil?
- [ ] Frases sem utilidade argumentativa?
- [ ] Parágrafo com mais de 10-12 linhas reunindo mais de um argumento/fato/fundamento? (redacao-rdaa.md — extensão do parágrafo)
- [ ] Número repetido por extenso entre parênteses ("5 (cinco) dias")? Regra: 1-9 por extenso, 10+ numeral, nunca os dois juntos (redacao-rdaa.md / Manual §2.8)
- [ ] Verbo de comando ("exige", "impõe", "veda"...) atribuindo à parte/advogado o poder de ordenar o julgador? (admitido quando o sujeito é a lei/precedente/contrato — redacao-rdaa.md)
- [ ] Existe qualquer dois-pontos na peça final? Corrigir antes da entrega (redacao-rdaa.md).
- [ ] Existe aposto explicativo isolado por parênteses ou travessões pareados? Reescrever em frase própria (redacao-rdaa.md).

---

## V. Provas e amarração probatória

- [ ] Todo fato relevante possui documento identificado?
- [ ] O documento é citado imediatamente após o fato narrado?
- [ ] Existe coerência cronológica?
- [ ] Há documento mencionado sem explicação de sua relevância?
- [ ] Há argumento sem suporte probatório?
- [ ] Existe prova importante ignorada?
- [ ] Existe ausência de prova relevante não explorada estrategicamente?
- [ ] Há contradição documental interna?
- [ ] A narrativa adversa foi confrontada com a prova disponível?

Encadeamento obrigatório: **Fato → Prova/Documento → Fundamento → Consequência jurídica**

---

## VI. Consequência jurídica

- [ ] Cada tese produz consequência processual prática?
- [ ] O texto demonstra risco processual, nulidade, incoerência, ausência de prova ou comportamento contraditório?
- [ ] Existe conclusão clara ao final de cada tópico?
- [ ] Os pedidos decorrem logicamente da fundamentação?
- [ ] Há pedidos genéricos sem ancoragem na narrativa?
- [ ] Há pedidos incompatíveis com os fatos narrados?
- [ ] Os pedidos vêm precedidos de uma frase introdutória sem dois-pontos antes das alíneas? (redacao-rdaa.md — pedidos em cascata)
- [ ] Há pedidos redundantes entre si (um já abrange o outro)? (redacao-rdaa.md)
- [ ] Havendo mais de um pedido possível, estão hierarquizados em cascata (principal → preliminar → sucessivo → sucumbência por último)? (redacao-rdaa.md)

---

## VII. Legislação e jurisprudência

Padrão obrigatório de citação legal (redacao-rdaa.md):
> "CPC, art. 373, inciso II"

Nunca:
> "inciso II do art. 373 do CPC"

- [ ] As leis seguem o padrão correto?
- [ ] Há jurisprudência inventada ou não verificada? → Sinalizar: `[Atenção: inserir jurisprudência real]`
- [ ] A jurisprudência citada realmente sustenta a tese apresentada?
- [ ] Há excesso de citações decorativas?
- [ ] As citações são úteis ou apenas encorpam o texto?
- [ ] Há doutrina desnecessária?
- [ ] Há súmulas sem pertinência ao caso?

---

## VIII. Densidade argumentativa

- [ ] O texto demonstra domínio do caso concreto?
- [ ] Há argumentação estratégica ou apenas postura defensiva/reativa?
- [ ] A peça enfrenta o problema central ou o contorna?
- [ ] Há exploração de: má-fé adversa, comportamento contraditório, inovação tardia, manipulação narrativa, deslocamento artificial da controvérsia?
- [ ] O texto cria percepção de credibilidade e segurança técnica?
